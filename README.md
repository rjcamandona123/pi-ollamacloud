# pi-ollamacloud

[![Pi Package](https://img.shields.io/badge/pi-package-blue)](https://github.com/rjcamandona123/pi-ollamacloud)

Pi provider for Ollama Cloud.

## Install

```bash
pi install git:github.com/rjcamandona123/pi-ollamacloud
```

## Login

Run `/login` and select **Ollama Cloud**, then paste your API key from https://ollama.com/settings/keys.

## Models

- Beam 501B (cloud)
- Gemma 4 31B (free cloud)
